# Nar Patisserie

Курсовой проект: статический сайт кондитерской Nar Patisserie. На сайте есть главная страница, каталог десертов и напитков, корзина заказа и страница контактов.

## Что реализовано

В проекте реализованы адаптивная верстка, каталог с фильтрацией и сортировкой, добавление товаров в корзину, изменение количества товаров, расчет итоговой суммы и формы для оформления заказа и обратной связи.
